# บ้านผีสิง V1.8.2 — Ghost Showcase & Action Rail

Playtest UI polish for the pre-game ghost reveal and main gameplay layout. Gameplay rules/data are unchanged.

## Ghost selection
- Ghost selection is now art-first: full-bleed original ghost artwork with only ghost name + archetype subtitle.
- Nine ghost cards form a slightly overlapping horizontal hand for a physical-card feel.
- Random cycle still highlights cards with audio feedback.
- The selected ghost gets a stronger lift/glow treatment.
- Final selected ghost is shown as a clean poster-style card for ~2.5 seconds.

## Game-start countdown
- After the selected ghost showcase, all clients receive a server-timed 5-second countdown: 5 → 4 → 3 → 2 → 1 → เกมเริ่ม.
- The server does not start the room/turn until the countdown finishes, so no hidden turn time is lost.

## Main gameplay layout
- Draw Amulet, Draw Sacrifice, Trade, Ritual and Skill move into a compact vertical action rail on the right of the board.
- Secondary actions use the same gold family as the main roll CTA but remain smaller.
- END stays separated at the bottom of the rail.
- On smaller screens the action rail collapses back to a compact grid.

## Safety
- Uses the original V1.8 card artwork/assets.
- Patch script verifies the target branch and V1.8.1 base.
- Patch script backs up modified files and automatically restores them if patching or tests fail.
