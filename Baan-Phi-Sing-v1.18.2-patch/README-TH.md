# บ้านผีสิง v1.18.2 revision 2 — ปุ่มอาร์ทและไอคอนสถานะ

สำหรับฐาน v1.18.1 บน branch v1.8-playtest

## สิ่งที่ปรับ
- ปุ่มแลกเปลี่ยน / ทำพิธี / สกิลพิเศษ / จบเทิร์น ใช้ PNG 4 สถานะ
- เปลี่ยน AP ในช่องค่าใช้จ่ายเป็นข้อความ ธูป ที่เกมแสดงเอง
- สกิล remote_help แสดง ฟรี เมื่อกติกาเดิมให้ใช้จาก catHelp
- ไอคอน HP เงิน สติ ธูป ซัพพอร์ต ขนาดแสดง 24–28 px
- ปรับระยะตัวเลขและเว้นลายเชิงเทียนในกรอบสถานะ
- บนมือถือ ปุ่มทั้ง 4 เรียงแนวนอน

## ติดตั้งแบบวางทั้งโฟลเดอร์
1. แตก ZIP แล้ววางโฟลเดอร์ Baan-Phi-Sing-v1.18.2-patch ในรากโปรเจกต์ ข้าง package.json
2. เปิด Terminal ที่รากโปรเจกต์ แล้วรัน:

```sh
node Baan-Phi-Sing-v1.18.2-patch/install.cjs
```

สคริปต์ตรวจเวอร์ชันและ hash สำรองไฟล์เดิม ติดตั้ง และรัน npm test ถ้าทดสอบไม่ผ่านจะคืนไฟล์เดิม
เมื่อขึ้น PATCH v1.18.2 PASS ใช้คำสั่งนี้เพื่อ stage เฉพาะไฟล์แพตช์:

```sh
node Baan-Phi-Sing-v1.18.2-patch/stage.cjs
```

ยังไม่มีการ commit หรือ Deploy อัตโนมัติ

## ตรวจสอบที่ทำแล้ว
- ตรวจ JavaScript syntax ผ่าน
- ทดสอบ UI ในเบราว์เซอร์ด้วย HTML/CSS และโค้ดจัดหน้าเกมจริง โดยใช้ข้อมูลตัวอย่าง
- ยืนยันปุ่มเดิมและ handler เดิมยังอยู่; enabled เรียก handler, disabled ไม่เรียก
- ยืนยันโหนดตัวเลขเดิม อัปเดตตัวเลขได้ และ redraw ไม่เพิ่มไอคอนซ้ำ
- ตรวจภาพหน้าจอที่ความกว้าง 1920 / 1366 / 390 px
- ตรวจภาพปุ่ม disabled ว่าใช้ไฟล์ของสถานะนั้นครบ 4 ปุ่ม
- client tests v1.17.1 และ v1.18.1 ผ่าน
- server.js และ public/app.js ตรงกับฐาน v1.18.1 ทุกไบต์

ข้อจำกัด: ยังไม่ได้ทดสอบห้องผู้เล่นหลายคนจริง และไม่ได้รัน npm test ทั้งชุดในเครื่องนี้ เนื่องจากสำเนาโปรเจกต์มีอาร์ทเดิมและ dependencies ไม่ครบ (v1.18 client test ขาด S01-v118.png) ตัวติดตั้งจะรันทดสอบทั้งชุดบนโปรเจกต์เต็มของติม
