# อัปเดตเลย์เอาต์ v1.13.1

แพตช์นี้ปรับเฉพาะหน้าจอเกมต่อจาก v1.13.0: กระดาน 3×3 เป็นจัตุรัส, แถบผู้เล่นและผีแคบลง, โปรไฟล์ตัวเองเปิดจากปุ่มด้านบน, ปุ่มการกระทำกระชับขึ้น และกระเป๋าล่างย่อ/ขยายทั้งแผงได้โดยไม่บังกระดาน

## วิธีลงแพตช์

1. ดาวน์โหลด ZIP แล้วแตกไฟล์ไว้ใน **โฟลเดอร์หลักของเกม** ที่มี `server.js`, `package.json`, `public` และ `lib/accounts.cjs`
2. เปิด Terminal ในโฟลเดอร์หลักนั้น แล้วตรวจด้วยคำสั่ง `node Baan-Phi-Sing-v1.13.1-layout/install-v1.13.1.cjs --check`
3. ถ้าขึ้น `CHECK PASSED` ให้ติดตั้งด้วย `node Baan-Phi-Sing-v1.13.1-layout/install-v1.13.1.cjs`
4. รันทดสอบ `npm test`
5. คอมมิต/อัปโหลดไฟล์ไป GitHub แล้วเลือก Deploy Latest Commit ใน Railway จากนั้น Hard Refresh หน้าเกม

ตัวติดตั้งแก้เพียง 3 ไฟล์หน้าจอ สำรองไฟล์เดิมไว้ในโฟลเดอร์แพตช์ และหยุดก่อนหากพบไฟล์ที่ไม่ตรงกับ v1.13.0
