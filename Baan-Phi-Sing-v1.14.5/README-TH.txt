บ้านผีสิง v1.14.5 — อาร์ต Lobby และห้องเตรียมพร้อม
ติดตั้งต่อจาก v1.14.3

1. แตก ZIP จะได้โฟลเดอร์ Baan-Phi-Sing-v1.14.5
2. ลากโฟลเดอร์นี้ทั้งโฟลเดอร์เข้า Codespaces ไว้ระดับเดียวกับ server.js, package.json และ public
   ไม่ต้องลากไฟล์ใน files ไปทับเอง
3. เปิด Terminal ที่โฟลเดอร์หลักเกม แล้วรัน:
   node Baan-Phi-Sing-v1.14.5/install-v1.14.5.cjs
4. เมื่อขึ้นติดตั้งสำเร็จ ให้รันทีละบรรทัด:
   git add public/index.html public/app.js public/pregame-theme.css public/pregame-ui.js public/assets/ui package.json package-lock.json
   git commit -m "Style lobby and ready room v1.14.5"
   git push
5. Railway service เกม: รอ Deployment ของ commit ใหม่สำเร็จ (ถ้าไม่เริ่มอัตโนมัติ ให้ Deploy Latest Commit)
6. เปิดเว็บแล้ว Hard Refresh: Mac Cmd+Shift+R / Windows Ctrl+Shift+R

ถ้าตัวติดตั้งบอกไฟล์ไม่ตรงกับ v1.14.3 ให้หยุดและส่งข้อความนั้นให้มีนาตรวจ ไม่ต้องฝืนวางทับ
ตัวติดตั้งตรวจไฟล์ทั้งหมดและสำรองไฟล์ที่เปลี่ยนก่อนติดตั้ง ไม่เพิ่ม dependency
ไม่ต้องแก้ Supabase หรือ Railway Variables

ดีไซน์ใหม่
- ฉากโถงบ้านผีสิงแสงเทียนทองและแสงฟ้าตามเรฟ ไม่มีปุ่มหรือข้อความฝังในภาพ
- Lobby: โปรไฟล์ซ้ายบน สกุลเงิน/เครื่องมือขวาบน ชื่อเกมซ้าย การ์ดสร้างห้องและเข้าห้องคู่กัน
- เมนูล่าง ร้านค้า / กระเป๋า / ตัวละคร / เพื่อน พร้อมไอคอน SVG
- Room: 6 การ์ดตัวละคร ขอบทอง สีประจำที่นั่ง ชื่อผู้เล่น/สาย/ความพร้อมจากข้อมูลจริง
- ปุ่มเลือกตัวละครและ Playtest Settings ล่างซ้าย ปุ่มเตรียมพร้อม/เริ่มเกมล่างขวา
- แผงเพื่อนสไตล์เดียวกัน เปิดปิดได้และไม่บังช่องผู้เล่นบนเดสก์ท็อป
- เอาฟันเฟืองลอยออกเฉพาะ Lobby/Room ใช้ปุ่มตั้งค่าในแถบด้านบน
- ปิดตั้งค่าแล้วคืนโฟกัสให้ปุ่มตั้งค่าของหน้าปัจจุบัน
- ฟอนต์ไทยและไอคอนมากับแพตช์ ไม่ต้องพึ่งฟอนต์จากเว็บอื่น
- ข้อมูลบัญชี เงิน ตัวละคร กลไกเกม และหน้า Login/หน้าเกมหลักคงระบบเดิม

ผลตรวจ
- ทดสอบหน้าจอ 1920x1080 และ 1366x768 พร้อมเปิดแผงเพื่อน ไม่มี scroll ล้นหน้า
- สอง client จริงบนเซิร์ฟเวอร์ทดสอบ: สร้าง/เข้าห้อง เลือกและยืนยันตัวละคร Ready/Unready สิทธิ์โฮสต์ เริ่มเข้าสู่สุ่มผี
- เปิดปิดตั้งค่าและแผงเพื่อน ปุ่มฟันเฟืองลอยไม่บังปุ่มปิด
- ผ่าน friends-ui-test.cjs และ shop-dom-test.cjs และตรวจ syntax ของ JavaScript ที่แก้
- ภาพพรีวิวใช้บัญชีและรายชื่อเพื่อนจำลอง; ภาพ Room เพิ่มที่นั่งตัวอย่างหลังทดสอบผู้เล่นจริงสองคน
- ไม่ได้ทดสอบ Google OAuth บน production และยังไม่ได้ Deploy
- ชุดทดสอบเต็มมี assertion เก่าจาก v1.14.2 ที่เช็ก startBtn ต้องอยู่ก่อน lobbyPlayers ใน HTML; รอบนี้ไม่ได้แก้กฎการทดสอบนั้น
