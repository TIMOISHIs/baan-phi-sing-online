# บ้านผีสิง V1.8.4 — Mood + Curse Telegraph

Playtest polish patch based on V1.8.3.

## Room cards
- Room tiles on the 3×3 board now use the original room artwork as a full-card background.
- Header and effect bands become translucent overlays instead of solid white panels.
- Keeps room name, Fear, short effect, pawns, legal/illegal movement states, and click-to-read behavior.

## Ghost Curse telegraph
- Crossing Curse 3/6 triggers a one-time warning overlay + warning sound for ~2.5s.
- The in-game Ghost card glows red while Curse is 3–5/6.
- Reaching Curse 6/6 triggers a stronger full-screen Curse warning and temporarily locks turn actions.
- The Curse effect resolves after the warning, then Curse resets to 0 and the warning cycle can happen again.
- Reload/reconnect during a Curse resolution can reconstruct the active warning from server state.

## Card reveal timing
- Normal Amulet draw reveal: ~2.8s.
- Event card reveal: ~3.2s.
- Sacrifice reveal remains shorter (~2.2s).

## Safety
- Server remains authoritative for Curse progress and Curse damage.
- Auto-end is paused while Curse is resolving.
- Existing V1.8.3 mandatory-decision lock remains intact.


> Patch package hotfix: corrected the local post-apply UI assertion script; game logic/content unchanged.
