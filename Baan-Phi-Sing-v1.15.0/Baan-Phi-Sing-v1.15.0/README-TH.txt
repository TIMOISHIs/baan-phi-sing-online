บ้านผีสิง v1.15.0 — ติดตั้งต่อจาก v1.14.6

1. แตก ZIP แล้วนำโฟลเดอร์ Baan-Phi-Sing-v1.15.0 ทั้งโฟลเดอร์เข้า Codespaces
   วางระดับเดียวกับ server.js, package.json และ public ไม่ต้องคัดลอกไฟล์ใน files ทับเอง
2. เปิด Terminal ที่โฟลเดอร์หลักเกม แล้วรัน:
node Baan-Phi-Sing-v1.15.0/install-v1.15.0.cjs
3. เมื่อขึ้นติดตั้งสำเร็จ รันทีละบรรทัด:
git add server.js public/app.js public/index.html public/dashboard.js public/gameplay115.js public/gameplay115.css package.json package-lock.json v115-test.cjs
git commit -m "Update movement and board UX v1.15.0"
git push
4. รอ Railway deploy commit ใหม่สำเร็จ ถ้าไม่เริ่มเองให้ Deploy Latest Commit ที่ service เกม
5. เปิดเว็บแล้ว Cmd+Shift+R บน Mac หรือ Ctrl+Shift+R บน Windows

ตัวติดตั้งตรวจไฟล์ฐานและสำรองไฟล์ที่เปลี่ยน หากแจ้งไฟล์ไม่ตรงให้หยุดและส่งข้อความมาตรวจ
ไม่ต้องแก้ Supabase หรือ Railway Variables
รอบนี้แก้ server.js ด้วย แนะนำติดตั้งเมื่อทุกห้องเล่นจบแล้ว

รายการอัปเดต
- ชื่อห้องด้านบนกลาง Fear ขวาบน คำอธิบายตรงกลาง
- ห้องที่เดินไม่ได้มืดลงระหว่างเลือกเดิน ห้องที่เดินได้ใช้ไฮไลท์สีตามประเภทห้อง
- แลกเปลี่ยน/ทำพิธี/สกิล/จบเทิร์นย้ายไปขอบขวา แยกจากเด็คและกองทิ้ง
- กองที่จั่วได้เรืองแสงเป็นจังหวะ; เคารพการตั้งค่าลดการเคลื่อนไหวของระบบ
- กระเป๋าเปิดอัตโนมัติเมื่อเข้าเกมใหม่ ผู้เล่นยังย่อเองได้
- ทอยเพื่อเดินขึ้นกลางจอ รวมถึงทอยหนีและเดินจากสกิลหมอธรรม
- กดห้องที่ไฮไลท์เพื่อเดินทันที ไม่ต้องกดเดินต่อด้วยค่าสตินี้
- ใช้การ์ดเพิ่ม/ลดสติก่อนเลือกห้องได้ตามค่าและต้นทุนธูปเดิม
- ไม่มีทางเดิน: เลือกอยู่ห้องเดิมได้เพื่อไม่ใช้การ์ด; ถ้ากฎบังคับเดินและมีทาง ต้องเลือกห้อง
- หมากใช้ภาพตัวละครในวงกลมขอบสีประจำผู้เล่น ไม่ใช่อาร์ตหัวแยกที่วาดใหม่
- ถึงเทิร์นเรา: แจ้งกลางจอเป็นจังหวะ หยุดเมื่อขยับเมาส์ แตะ หรือกดแป้นพิมพ์
- คงปุ่มปรับขนาดฟอนต์จาก v1.14.6

ผลตรวจ
- v115-test.cjs: เดินทันที เพิ่มสติ +2 ป้องกันกดซ้ำ ห้องไม่ถูกต้อง บังคับเดิน/เลือกอยู่ ไม่มีทางเดิน สิทธิ์และช่วงล็อก
- ชุดสกิลหมอธรรมและเวลาเทิร์น 2 นาทีผ่าน รวมถึงผู้ถูกช่วยเดินนอกเทิร์น
- v190-regression-test.cjs: เส้นทางแนวตั้ง/แนวนอนและห้องที่ขวางทางผ่าน
- เบราว์เซอร์ Chromium 1920x1080 และ 1366x768: กระดานจัตุรัส ไม่ล้นหน้า ตำแหน่งข้อความ/ปุ่ม
- ตรวจแสดง/ย่อกระเป๋า ปุ่มทอยกลางจอ แจ้งเตือนเฉพาะเทิร์นและหยุดหลังผู้เล่นตอบสนอง
- ภาพพรีวิวใช้ข้อมูลทดสอบ ไม่ใช่ห้อง production
- ยังไม่ได้ Deploy หรือทดสอบเล่นเต็มเกมบน production/Safari
