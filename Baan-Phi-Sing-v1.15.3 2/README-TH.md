# บ้านผีสิง v1.15.3 — Layout ตามเรฟ

ใช้ต่อจาก v1.15.2 เท่านั้น เป็นแพตช์หน้าเกม 3 ไฟล์ ไม่เปลี่ยนกติกา ฐานข้อมูล หรือไฟล์การ์ด

## ติดตั้งใน Codespaces
1. แตก ZIP จะได้โฟลเดอร์ Baan-Phi-Sing-v1.15.3
2. ลากโฟลเดอร์นี้ทั้งโฟลเดอร์ เข้าโฟลเดอร์หลักเกมที่เห็น server.js, package.json และ public อยู่ด้วยกัน ไม่ใส่ใน lib หรือ public และไม่ซ้อนชื่อโฟลเดอร์สองชั้น
3. เปิด Terminal > New Terminal จากโฟลเดอร์หลัก แล้วพิมพ์ทีละบรรทัด:

```sh
node Baan-Phi-Sing-v1.15.3/install.cjs --check
node Baan-Phi-Sing-v1.15.3/install.cjs
git diff --cached --stat
git commit -m "Update game layout v1.15.3"
git push
```

ให้รันบรรทัดถัดไปเมื่อบรรทัดก่อนหน้าสำเร็จ ถ้าขึ้น ERROR ให้หยุดแล้วส่งข้อความมาดู
ตัวติดตั้งสำรองไฟล์เดิมและ Stage เฉพาะไฟล์แพตช์ให้ ไม่ใช้ git add .
หากแจ้งมีไฟล์ Stage ค้าง ให้ตรวจและจัดการงานเดิมก่อน ไม่ต้องลบทิ้ง
หลัง Push เปิด Railway บริการเกมตัวเดิม รอ deployment ของ commit นี้เป็น Deployment successful และ Active แล้วเปิดเกมใหม่
แนะนำติดตั้งช่วงไม่มีคนเล่น เพราะการ Deploy อาจรีสตาร์ตเซิร์ฟเวอร์
