# บ้านผีสิง v1.17.1 — Amulet presentation polish

- การ์ด Amulet ในกระเป๋าลอยขึ้นเล็กน้อยและนิ่งเมื่อชี้เมาส์
- เมื่อหนีห้องกับดักหรือคำสาปสำเร็จ แสดง “หลบหนีสำเร็จ” 1.5 วินาทีหลังผลเต๋าจบ ก่อนเลือกห้องออก
- เมื่อเจ้าของเทิร์นจั่ว Amulet ต่อเนื่อง ใบเดิมเก็บเข้ากระเป๋าเร็วขึ้นเพื่อเปิดใบใหม่ทันที
- ผู้เล่นอื่นเห็น Amulet ที่เพื่อนจั่วเป็นการ์ดขนาดเล็กด้านซ้ายของ Board 1.5 วินาที โดยไม่ขวางการเล่นหรือแชท
- Event ยังแสดงกลางจอให้ผู้เล่นทุกคนรับรู้
- Amulet เริ่มเกม 3 ใบยังเปิดทีละใบ แต่รวมเวลาเหลือประมาณ 3–4 วินาที

## ตรวจสอบแล้ว

- Syntax: `server.js`, `public/app.js`, `public/ui1168.js`
- Server regression: แผนที่สมดุล 1,800 ครั้ง, Fear, ห้องคำสาป/กับดัก และทางออกพิเศษ
- Client regression: hover, ป็อปอัปหนีสำเร็จ, การ์ดจั่วของผู้เล่นอื่น, จั่วต่อเนื่อง และจังหวะแจกเริ่มเกม
- Regression หลัก v1.8, v1.8.5, v1.8.6, v1.9, v1.13, v1.15 และ v1.17 ผ่าน
