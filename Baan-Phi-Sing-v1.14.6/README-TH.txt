บ้านผีสิง v1.14.6 — ติดตั้งต่อจาก v1.14.5
1. แตก ZIP แล้วนำโฟลเดอร์ Baan-Phi-Sing-v1.14.6 ทั้งโฟลเดอร์วางใน Codespaces ระดับเดียวกับ server.js, package.json และ public
2. เปิด Terminal ที่โฟลเดอร์หลักเกม:
node Baan-Phi-Sing-v1.14.6/install-v1.14.6.cjs
3. เมื่อขึ้นติดตั้งสำเร็จ รันทีละบรรทัด:
git add public/index.html public/pregame-theme.css public/pregame-ui.js public/app.js package.json package-lock.json
git commit -m "Update lobby and font settings v1.14.6"
git push
4. รอ Railway deploy commit ใหม่สำเร็จ ถ้าไม่เริ่มเองให้กด Deploy Latest Commit ที่ service เกม
5. เปิดเว็บแล้ว Cmd+Shift+R บน Mac หรือ Ctrl+Shift+R บน Windows

หากตัวติดตั้งแจ้งไฟล์ฐานไม่ตรง ให้หยุดแล้วส่งข้อความมา ไม่ต้องฝืนทับไฟล์
มีสำรองไฟล์ก่อนติดตั้ง ไม่ต้องแก้ Supabase, Variables หรือเพิ่ม dependency

สิ่งที่ปรับ:
- ลดโลโก้เฉพาะ Login โดยคงขนาด Lobby
- แถบเงิน/ทอง/สถิติ/กติกา/ตั้งค่าบน Lobby ใช้กรอบและลำดับเดียวกับ Room พร้อมปุ่มออกจากระบบ
- แถบเพื่อนด้านขวาเปิดปิดด้วยลูกศรใน Lobby และ Room; เมนูเพื่อนด้านล่างยังใช้เปิดแผงเดียวกัน
- ตกแต่งแถบเมนูล่าง กรอบทอง มุมประดับ สถานะ hover/focus และไอคอนรถเข็น
- ตั้งค่าเพิ่มขนาดตัวหนังสือบนกระดาน 80–140% และคืนค่า 100% โดยมีผลกับชื่อห้อง คำอธิบาย และ Fear
- จำฟอนต์เฉพาะเบราว์เซอร์นี้ ไม่เปลี่ยนขนาดตัวหนังสือของเพื่อน
- ฟอนต์ไม่ได้ขยายทั้งหน้า เพื่อคงตำแหน่งกระดานและปุ่ม

ผลตรวจ:
ทดสอบสอง client บนเซิร์ฟเวอร์ท้องถิ่น สร้าง/เข้าห้อง เลือกตัวละคร พร้อม/ยกเลิกพร้อม สิทธิ์โฮสต์ และเริ่มสุ่มผี
ตรวจหน้าจอ Lobby/Room 1920x1080 และ 1366x768 ไม่ล้นหน้า
ภาพพรีวิวใช้ข้อมูลบัญชี/เพื่อนจำลอง และเพิ่มผู้เล่นตัวอย่างเพื่อดู layout
ยังไม่ได้ Deploy หรือทดสอบ OAuth บน production
