# บ้านผีสิง v1.18.0

แพตช์สำหรับฐาน v1.17.1 บน branch `v1.8-playtest`

## สิ่งที่เปลี่ยน

- การเดินปกติหัก Fear สะสมทุกห้องที่เดินเข้า รวมปลายทาง ไม่นับห้องเริ่มต้น หัก Fear อุปกรณ์ครั้งเดียวตอนคำนวณสติ และคงขีดจำกัดระยะจากผลเต๋าเดิม
- พรีวิวเลือกเฉพาะเส้นทางที่จ่ายไหว หากมีหลายเส้นทางเลือกเส้นทางที่เสียสติน้อยที่สุดภายในระยะเดิน การเดินปกติยังหยุดเมื่อเข้าห้องบอส/กับดัก/คำสาป
- S01 แคล้วคลาด: ป้องกัน Event ผลลบให้ตัวเองหนึ่งครั้ง ฟรี ไม่ทอย และใช้ได้เมื่อระบบถามแม้เป็นเทิร์นคนอื่นหรือธูปหมด
- S04 อยู่ยงคงกระพัน: ป้องกันผล Curse ทั้งชุดให้ตัวเองเฉพาะการระเบิดครั้งนั้น ฟรี ไม่ทอย ผู้เล่นอื่นยังรับผล และ Curse รอบต่อไปทำงานตามปกติ ไม่ป้องกันการสวนกลับจากพิธีกรรม
- S02: ไปห้องใดก็ได้ที่ไม่เต็ม รวมบอส/กับดัก/คำสาป แต่ใช้หนีจากห้องกับดัก/คำสาปไม่ได้
- S05/S06: เลือกปลายทางตามแนวทแยงได้ เช่น 9 → 5 หรือ 1 ข้ามห้องพิเศษหรือห้องเต็มระหว่างทางได้ ตรวจความจุเฉพาะปลายทาง ห้ามใช้หนีจากกับดัก/คำสาป
- S02/S05/S06 ใช้หลังทอยในเทิร์นตัวเองได้ รวมถึงหลังเดินปกติแล้ว ใช้หลายใบได้เมื่อยังมีธูป ใบละหนึ่งธูป ไม่ใช้สติ เมื่อใช้ก่อนเดินปกติจะถือว่าจบการเดินปกติครั้งนั้น
- S03/S09 หนีเฉพาะห้องกับดัก; S07/S08 หนีเฉพาะห้องคำสาป เสียหนึ่งธูปและเลือกออกหนึ่งห้องติดกัน ไม่คิด Fear ไม่ทอยซ้ำ
- ทุกใบใช้แล้วลงกองทิ้ง ไม่มีเงื่อนไขเต๋า และไม่มีการเพิ่ม Curse จากการทอยคาถาอีก
- เปลี่ยนอาร์ทเก้าใบด้วย PNG ต้นฉบับที่ส่งมา โดย S03-1 จับคู่ S04 ตรวจ SHA-256 เทียบต้นฉบับครบทุกใบ

## ผลตรวจสอบ

- ชุดทดสอบตาม `npm test` ทั้ง 23 ชุดผ่าน รวมระบบเดิมและชุดใหม่
- เทียบเส้นทางกับการไล่เส้นทางอิสระ 250 แผนที่ รวมการเดินอ้อม สติไม่พอ ขีดจำกัดระยะ และการหักสติจริง
- ทดสอบการใช้คาถาหลังเดิน ใช้หลายใบ ธูปสุดท้าย การตรวจความจุซ้ำ และการหนีตามประเภทห้อง
- ทดสอบ Event แยกผลรายบุคคล, Curse ของผีเก้าแบบ, Curse รอบถัดไป, ผู้เล่นนอกเทิร์น, ธูปหมด, คำตอบซ้ำ, หมดเวลา และคำสาปที่ซ้อนกับตัวเลือกเดิม
- ทดสอบ client logic ของปุ่มและป็อปอัปป้องกัน และตรวจอาร์ททั้งเก้าใบ
- ยังไม่ได้ยืนยันการเล่นจริงหลายหน้าจอครบทุกสถานการณ์ ควร playtest หลังติดตั้ง

## ติดตั้ง

อัปโหลด `Baan-Phi-Sing-v1.18.0-patch.zip` ไว้ที่รากโปรเจกต์ใน Codespaces แล้วรัน:

```bash
unzip -oq Baan-Phi-Sing-v1.18.0-patch.zip && node Baan-Phi-Sing-v1.18.0-patch/install.cjs
```

ตัวติดตั้งตรวจ branch และไฟล์ฐาน สำรองเฉพาะไฟล์ที่จะเปลี่ยน ติดตั้งแพตช์และรัน `npm test` หากการทดสอบไม่ผ่านจะคืนไฟล์เดิม ไม่ commit, push หรือ deploy เอง หากไฟล์ฐานต่างจากที่ตรวจไว้จะหยุดก่อนเขียน เพื่อรักษางานที่อาจแก้เพิ่มไว้

เมื่อขึ้น `PATCH PASS` สามารถตรวจ diff และ commit ตามขั้นตอนเดิมได้ โดยใช้รายการไฟล์ใน `manifest.json` เพื่อไม่เผลอใส่ ZIP หรือโฟลเดอร์สำรองเข้า commit
